# 多人共享记账系统：软件设计与建模

软件工程实验二工作仓库，承接实验一的多人共享记账系统需求。

## 目录

- `UML/`：PlantUML 源文件（`.puml`）及对应图片（`.png`）。
- `UI界面/`：各功能模块的界面设计图片。
- `实验报告.pdf`：完成后放在仓库根目录，由本人撰写。

## 版本管理

在本目录打开终端，使用以下命令查看和保存进度：

```powershell
git status
git add README.md UML UI界面
git commit -m "补充设计文件"
```

提交报告时另行执行 `git add 实验报告.pdf`。修改 UML 源文件后，应同步重新导出对应图片。
